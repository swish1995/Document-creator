문서 생성기

버전 1.0.0

인체공학 평가 결과를 기반으로 안전문서를 생성하는 도구

📋 프로그램 소개

문서 생성기는 Skeleton Analyzer에서 분석한 인체공학 평가 결과를 바탕으로 전문적인 안전문서를 자동으로 생성하는 도구입니다.

Excel 파일에서 평가 데이터를 불러와 미리 정의된 템플릿과 결합하여 PDF 또는 PNG 형식의 문서를 생성합니다. 다수의 작업자와 다양한 평가 유형을 한 번에 처리할 수 있어 대량의 문서 작성 작업을 효율적으로 수행할 수 있습니다.

✨ 주요 기능

📊 데이터 처리

Excel 파일 로드 .xlsx, .xls 형식의 평가 데이터 파일 지원
자동 매핑 Excel 컬럼과 템플릿 필드 자동 연결
수동 매핑 조정 필요 시 매핑 관계 직접 수정 가능
행 선택 특정 행만 선택하여 문서 생성

📄 문서 생성

다중 템플릿 지원 RULA, REBA, OWAS, NLE, SI 템플릿 동시 적용
PDF/PNG 출력 용도에 맞는 출력 형식 선택
PDF 병합 여러 문서를 하나의 PDF로 통합
ZIP 아카이브 다수의 파일을 압축하여 제공

👁️ 미리보기

실시간 미리보기 선택한 행의 데이터로 문서 미리보기
다중 패널 최대 5개 템플릿 동시 미리보기

📐 지원 템플릿

템플릿 평가 방법 설명
RULA 상지 반복 작업 평가 목, 몸통, 어깨, 팔, 손목 자세 평가
REBA 전신 자세 평가 전신 자세 및 부하를 종합 평가
OWAS 작업 자세 분류 등, 팔, 다리, 하중 조합 분류
NLE 들기 작업 권장 한계 NIOSH 들기 방정식 기반 평가
SI 반복 작업 스트레인 손/손목 반복 작업 위험도 평가

RULA (Rapid Upper Limb Assessment)

상지 중심의 반복 작업에 적합한 평가 결과 문서

점수 범위 1-7점
포함 정보 그룹A/B 점수, 최종 점수, 조치 수준

REBA (Rapid Entire Body Assessment)

전신 자세와 외부 부하를 종합적으로 평가한 결과 문서

점수 범위 1-15점
포함 정보 그룹A/B 점수, 최종 점수, 위험 수준

OWAS (Ovako Working Posture Analysis System)

작업 자세를 4자리 코드로 분류한 결과 문서

코드 구성 등(1-4), 팔(1-3), 다리(1-7), 하중(1-3)
포함 정보 자세 코드, 조치 등급(AC 1-4)

NLE (NIOSH Lifting Equation)

들기 작업의 권장 무게 한계 평가 결과 문서

계수 항목 HM, VM, DM, AM, FM, CM
포함 정보 RWL(kg), 리프팅 지수(LI)

SI (Strain Index)

반복적인 손/손목 작업의 스트레인 평가 결과 문서

평가 항목 강도, 지속시간, 빈도, 자세, 속도, 작업시간
포함 정보 SI 점수, 위험도 판정
