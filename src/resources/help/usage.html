📖 사용 방법

🚀 시작하기

1

Excel 파일 열기

툴바의 📂 열기 버튼을 클릭하거나 Ctrl + O (macOS: Cmd + O)를 눌러 IMAS에서 내보낸 Excel 파일을 선택합니다.

2

템플릿 선택

오른쪽 패널에서 사용할 템플릿을 선택합니다. + 패널 추가 버튼으로 여러 템플릿을 동시에 선택할 수 있습니다.

3

행 선택

Excel 뷰어에서 문서를 생성할 행을 선택합니다. 체크박스로 개별 선택하거나, Ctrl + A로 전체 선택할 수 있습니다.

4

내보내기

툴바의 📤 내보내기 버튼을 클릭하여 출력 형식과 옵션을 설정한 후 문서를 생성합니다.

🔧 매핑 설정

매핑은 Excel 컬럼과 템플릿 필드를 연결하는 작업입니다. 프로그램이 자동으로 매핑을 시도하지만, 필요한 경우 수동으로 조정할 수 있습니다.

1

매핑 상태 확인

각 템플릿 패널에 매핑 상태가 표시됩니다. 매핑: 완료는 모든 필드가 연결됨을, 매핑: 5/8은 일부 필드가 미연결됨을 의미합니다.

2

매핑 편집

🔧 매핑 버튼을 클릭하여 매핑 다이얼로그를 엽니다. 각 템플릿 필드에 대해 연결할 Excel 컬럼을 선택할 수 있습니다.

💡 팁

매핑은 Excel 파일별, 템플릿별로 저장됩니다. 같은 Excel 파일을 다시 열면 이전 매핑 설정이 자동으로 적용됩니다.

📤 내보내기 옵션

출력 형식 PDF 또는 PNG 형식 선택. PDF는 인쇄용, PNG는 웹/프레젠테이션용에 적합
단일 파일로 병합 PDF 선택 시 모든 문서를 하나의 PDF로 통합 (PNG는 해당 없음)
템플릿별로 묶음 체크 시 템플릿별로 그룹화, 해제 시 행별로 그룹화
ZIP 아카이브 여러 파일 생성 시 자동으로 ZIP으로 압축

⚠️ 주의

많은 수의 문서를 생성할 경우 시간이 오래 걸릴 수 있습니다. 진행 중 취소 버튼으로 작업을 중단할 수 있습니다.

👁️ 미리보기

Excel 뷰어에서 행을 클릭하면 해당 행의 데이터로 미리보기가 업데이트됩니다. 실제 내보내기 전에 문서가 어떻게 생성될지 확인할 수 있습니다.

  • 미리보기는 선택된 모든 템플릿에 적용됩니다
  • 여러 패널을 추가하여 다양한 템플릿을 동시에 확인 가능
  • × 버튼으로 불필요한 패널 제거 가능

💡 팁

미리보기에서 데이터가 표시되지 않는 필드가 있다면 매핑 설정을 확인하세요.

⌨️ 단축키

Ctrl + O
Excel 파일 열기
Ctrl + E
내보내기

선택 해제

🔐 라이센스 등록

문서 생성하기 기능을 사용하려면 라이센스 등록이 필요합니다. IMAS와 동일한 라이센스를 사용하므로, 한 번 등록하면 두 프로그램 모두 사용할 수 있습니다.

1

라이센스 다이얼로그 열기

메뉴에서 도움말 → 라이센스 등록을 클릭합니다.

2

하드웨어 ID 복사

다이얼로그에 표시된 하드웨어 ID를 복사하여 라이센스 발급 담당자에게 전달합니다.

3

라이센스 키 입력

발급받은 라이센스 키(XXXX-XXXX-XXXX-XXXX 형식)를 입력하고 등록 버튼을 클릭합니다.

🔍 문제 해결

?

Excel 파일이 열리지 않아요

.xlsx 또는 .xls 형식인지 확인하세요. 파일이 다른 프로그램에서 열려 있으면 닫고 다시 시도하세요.

?

미리보기에 데이터가 표시되지 않아요

매핑 설정을 확인하세요. 🔧 매핑 버튼을 클릭하여 Excel 컬럼과 템플릿 필드가 올바르게 연결되어 있는지 확인합니다.

?

내보내기가 실패해요

저장 위치에 쓰기 권한이 있는지 확인하세요. 디스크 공간이 충분한지도 확인해 주세요.

?

문서 생성 버튼이 비활성화되어 있어요

라이센스가 등록되지 않은 상태입니다. 도움말 → 라이센스 등록 메뉴에서 라이센스를 등록하세요.

?

라이센스 키가 유효하지 않다고 나와요

라이센스 키는 하드웨어 ID와 연결되어 있습니다. 다른 컴퓨터의 라이센스 키는 사용할 수 없습니다. 올바른 하드웨어 ID로 발급받은 키인지 확인하세요.
